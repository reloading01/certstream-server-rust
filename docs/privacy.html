Privacy

What the hosted API at api.certstream.dev and this website record. A server you run yourself sends nothing to us.

Hosted API

Connections to api.certstream.dev pass through Cloudflare, which sees your IP address and request details under the Cloudflare privacy policy.

The server logs your IP address, the stream you picked, and when each connection opens and closes. We use these logs to enforce the per-IP connection limit and to find clients that abuse the service. Old entries are overwritten as the logs rotate, after about a week at current traffic.

The numbers on the Hosted API page are totals for the whole server, not per client. The API sets no cookies, and we do not sell or share the logs.

This website

certstream.dev is hosted on GitHub Pages, which logs visitors' IP addresses under the GitHub privacy statement.

Google Analytics counts page views and sets cookies to do so, and fonts load from Google Fonts. Both follow the Google privacy policy.

The light or dark theme you choose is saved in your browser and never sent anywhere.

Contact

Questions about your data, or a request to remove your IP address from the logs: contact@certstream.dev. Bugs and feature requests go to GitHub issues.
